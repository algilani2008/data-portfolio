# Data Portfolio | ملف أعمال تحليل البيانات

مشاريع تحليل بيانات مبنية على بيانات حقيقية منشورة، مع المنهجية والمصادر.

| المشروع | الوصف | الأدوات |
|---|---|---|
| [سوق العمل السعودي: التوظيف والتوطين](saudi-labor-market/) | تحليل المشتغلين السعوديين وغير السعوديين في 22 نشاطاً اقتصادياً (2021 - 2025) من بيانات الهيئة العامة للإحصاء | Excel، SQL، CSV، Python |
| [التضخم في السعودية حسب فئات الإنفاق](saudi-inflation/) | تحليل الرقم القياسي لأسعار المستهلك في 13 فئة إنفاق، والمساهمة في التضخم، وحاسبة لأثر التضخم على ميزانية الأسرة (2025 - 2026) | Excel، SQL، CSV، Python |
| [واط وأجر: تعرفة الكهرباء والمياه والأجور](watt-wage-ksa/) | قرارات أكتوبر 2026: تاريخ التعرفة منذ ما قبل 2016، وأثر الإصلاحات السابقة على التضخم، وحاسبة فواتير، وتوقع التضخم 2027 - 2028 بمونت كارلو، وأثر رفع حد نطاقات إلى 5,000 و6,000 ريال، مع [لوحة تفاعلية](watt-wage-ksa/dashboard/index.html) | Python (statsmodels)، SQL، Chart.js، CSV |
